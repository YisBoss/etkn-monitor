# etkn-monitor —— ETKN 监控（v2.5.2）

手机友好的 ETKN（ETK vNext）监控面板：队列规模、入库进度、完成速率与 ETA、分类任务统计、手动链路测速、失败任务重试、手动整理触发、异常媒体明细。

**v2.5.2 变化**（2026-09-17）——测速「TMDB 自建」改走代理真实路径：
- 测速目标 5 项（v2.5.1 加入 tmdb.relay.example.com）；v2.5.2 将该域测速改为经代理 192.168.1.1:7890 的 CONNECT 隧道发起，模拟 ETKN 业务真实路径（该域直连视角恒被重置，无法反映真实健康度）
- 面板只显示这一个真实结果，不并列直连/代理两行；测速历史副标题注明代理口径
- 其余 4 域名保持直连不动；超时 10 秒、异常阈值 5 秒、进历史（最近 50 轮）、异常推送逻辑均不变
- 实现：SPEEDTEST_TARGETS 每项带 proxy 参数，speedtest_one 支持 CONNECT 隧道分阶段计时（到代理→隧道建立→TLS→首字节）
- 验证：本地动态回归 19/19（原 16 项 + 新增 3 项：目标清单 5 项、tmdb.nb 经 7890 其余直连、哑代理连接拒绝优雅失败）

**v2.5.0 变化**（2026-09-17）——告警中心（飞书 Webhook 直推、零 token、不经 Hermes）+ 设置页：
- **设置页**：页头 ⚙️ 齿轮进入独立页（推送与巡检 / 推送历史 / 测速历史三页签）；飞书机器人 URL 配置+掩码回显（仅协议+域名+尾 4 位）、推送总开关、三类告警独立开关；巡检间隔全可配（500 检测默认 10 分钟，可选 5/10/15/30；定时测速默认关，可选 15/30/60/120 分钟；积压阈值默认 200）；设置持久化到本地文件，容器重启保留
- **TMDB 500 检测**：轮询今日 p115/records 异常明细，命中签名 `(?i)http[ _-]?500|status[=:]\s*500` 达阈值（默认 5 条）推送一次，回落自动重新布防；跨日重置
- **定时测速**：按间隔测 image.tmdb.org / shturl.cc / api.telegram.org / shared.55565576.xyz，连接失败或总耗时 >5 秒判定异常；历史保留最近 50 轮（手动+定时同池）；**shared 域因已知证书问题不参与自动告警**（手动测速保留）
- **积压告警**：分类队列任一类型排队 ≥ 阈值推送一次，回落后自动重新布防
- **推送契约**：`{"msg_type":"text","content":{"text":…}}`；飞书 HTTP 200 ≠ 成功，响应体 `code` 非 0 按失败处理并进历史；仅异常时推送、正常完全静默；面板保留最近 50 条推送历史
- **容错**：告警引擎 30 秒节拍线程，单检测器异常捕获入历史、线程存活；凭据失效仅记历史不崩溃
- 接口：GET/POST `/api/settings`、POST `/api/test-push`、POST `/api/check-500-now`、POST `/api/speed-now`、GET `/api/push-history`、GET `/api/speed-history`

## 部署（飞牛 fnOS）

```bash
# 1. 克隆（或复制）项目
cd /vol1/1000/docker
git clone https://github.com/YisBoss/etkn-monitor.git
cd etkn-monitor

# 2. 创建 .env（密码自填，绝不入仓）
cat > .env <<'EOF'
ETKN_BASE_URL=http://192.168.1.22:5257
ETKN_USERNAME=YisBoss
ETKN_PASSWORD=你的ETKN密码
MONITOR_PORT=8620
POLL_INTERVAL=15
EOF
chmod 600 .env

# 3. 启动
docker compose up -d

# 4. 验证
curl http://127.0.0.1:8620/api/meta
```

浏览器访问 `http://<NAS-IP>:8620`。

## 配置

| 变量 | 说明 | 默认 |
|---|---|---|
| ETKN_BASE_URL | ETKN 地址 | http://192.168.1.22:5257 |
| ETKN_USERNAME | 登录用户名 | YisBoss |
| ETKN_PASSWORD | 登录密码（必填） | 无 |
| ETKN_ETA_WINDOW | ETA 滚动窗口（分钟） | 10 |
| POLL_INTERVAL | 轮询间隔（秒） | 15 |
| MONITOR_PORT | 监听端口 | 8620 |

## 安全

- 零密钥设计：密码只放 `.env`（600 权限），不入代码、不入仓库；Git 已忽略 `.env`。
- 测速与重试均为手动触发，无任何定时任务。
- 重试仅转发 ETKN 官方接口；ETKN 的拒绝（409 等）原样透传展示。

## 接口

| 端点 | 方法 | 说明 |
|---|---|---|
| `/` | GET | 前端页面 |
| `/api/meta` | GET | 版本与配置 |
| `/api/status` | GET | 监控快照（轮询缓存） |
| `/api/speedtest` | POST | 手动测速（4 域名，无代理自然路由） |
| `/api/retry/{id}` | POST | 转发 ETKN retry-failed，透传状态与错误 |
