企微 App 收到、微信 App 收不到 → 属微信插件配置问题（非本程序问题），逐条核对：
① 微信里先关注「微信插件」（企微后台 → 微信插件 → 生成二维码，微信扫码关注）；
② 微信插件 → 右上角 → 设置 → 开启「接收企业消息」；
③ 企微管理后台 → 微信插件 → 不要勾选「成员使用微信插件时需要使用企业微信客户端」；
④ 企微手机端 → 左上角「≡」→ 设置 → 消息通知 → 不要勾选「仅在企业微信中接收消息」；
⑤ 应用不能被停用。
⚠️ 另：若管理端给应用设了「在微工作台中始终进入主页」，微信端只能收文本且限 20 字节，卡片会被转成文本并提示去企微查看 —— 这条是企微官方限制，本程序无法绕过。
ℹ️ 消息类型：微信端只认 text / textcard（markdown 会显示成「暂不支持此消息类型」）。本程序已按此选型——短告警发 textcard 卡片，超长正文回落 text。
